# ShoppingTherapy - where shopping feels like therapy!
A React.js Project - inlcudes all the major concepts of React.js like components, hooks, state (useState, useEffect), props etc.
React Bootstrap used for stylish and user-friendly UI.
A frontend shopping website - 
Header - Contains links to different pages like fashion, gadgets, cart etc.
Home page - Gives a general overview of the website, contains trending products list, category list.
Gadget Page - displays all the gadgets with category and price filter option.
Fashion Page - displays all the fashion products with category and price filter option.
Single-Product Page - displays the particular product user clicks on giving its detailed information and functionality to add to the cart.
Cart - displays the products that user adds to the cart through 'add to cart' button. It gives price summary including total price. The number can increased and decreased
as well as removed from the cart.
Components - Various components have been created like ProductList which can be used multiple times to display the products in different pages. Other components - Trending list,
Single-Product-Page, AddToCart etc.
Secured through firebase authentication for user registration, login, logout.
